# Fonts

`Baloo2[wght].ttf` is the variable Baloo 2 from Google Fonts (SIL Open Font License 1.1, `OFL.txt`). Unity's legacy `Text` cannot pick a weight from a variable font, so `instance.py` cuts fixed-weight files into `unity/MissionSplat/Assets/Art/Fonts/`, alongside a copy of the licence. Re-run it after replacing the source.
